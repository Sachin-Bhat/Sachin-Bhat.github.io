# README

Welcome — this is a quick launcher for the site. Use the file browser on the left to open pages (README, Devlog, etc.).

## Shortcuts
- `shift+h/l` — focus file browser / viewer
- `j/k` — move through files or scroll content (when viewer focused)
- `enter` — open selected file; `tab` — next tab; `shift+q` — close tab
- `esc` then type a command: `:help` (this page), `:q` (leave), `:set mouse=true|false`
